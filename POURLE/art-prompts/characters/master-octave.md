# 🧙‍♂️ Master Octave — Character Art Prompt

**Karakter spec**: Bkz. `docs/04-characters.md` Master Octave bible.

---

## Master Octave Full Reference Sheet Prompt

```
Character reference sheet for "Master Octave", 65-year-old male alchemist
mentor character in casual mobile puzzle game POURLE. Smooth 3D toon
render in Royal Match style with Pixar Toy Story / Inside Out smoothness.

Physical:
- Age: 65, warm grandfather appearance.
- Face: Rounded soft cheeks, gentle laugh lines around kind blue-green
  eyes, slightly hooked friendly nose, warm welcoming default expression.
- Hair: Pure white, half-bald top with neat white side hair (NOT messy
  Gandalf, NOT cartoonishly bald). Slightly curly texture.
- Beard: Full WHITE well-groomed beard, medium length, neat, sophisticated
  (NOT wild, NOT pointy wizard beard).
- Glasses: Half-rim reading glasses with thin gold frame, sitting low on
  nose, suggesting half-up half-down reading mode.
- Build: Average height, slightly stooped posture suggesting age but not
  frail, gentle hands.

Outfit:
- Cream-colored long tunic with amber piping along collar and cuffs.
- Burgundy waistcoat over tunic, brass-buttoned.
- Deep amber #5C3A21 sash/belt at waist.
- Loose comfortable wool trousers in warm brown.
- Soft leather slip-on shoes (NOT pointy magical boots).
- Foulard (silk neck scarf) in deep burgundy with subtle pattern.
- Slight mortar-and-pestle pendant on small chain (apothecary symbol, NOT
  occult).

NEVER include:
- Pointed wizard hat (NOT Gandalf, NOT Dumbledore).
- Star-pattern cape or robe (NOT Hogwarts).
- Crystal ball / pentagram / occult symbol.
- Threatening or stern default expression.
- Belly oversized fat exaggeration.
- Skeleton-thin frail look.
- Long flowing wizard robe to floor.
- Magic wand.

Color palette:
- Primary: Deep amber #5C3A21
- Secondary: Cream #F5E8D0
- Accent: Gold #D4B87A
- Skin: Warm fair-medium #E8C9A8

Style: Royal Match smooth 3D toon render (90% influence), Pixar polish
(10%). Vector-clean edges, soft gradient shading, bold readable shapes.
Mass-market neutral feel, warm grandfather warmth.

Mood reference: Disney's Geppetto warmth + Up's Carl Fredricksen warmth +
mature Pixar grandfather archetype.

Negative prompt: NO painterly, NO oil painting, NO brushstrokes, NO Clair
Obscur, NO gothic witch, NO Hogwarts, NO Saruman, NO scary wizard, NO
anime exaggeration, NO chibi, NO magical realism dark.

Output format: Multi-pose character reference sheet showing front, 3/4,
side, with 5 portrait expression variants (neutral, happy, surprised,
proud, wave). Crisp 4K, perfect for asset pipeline.
```

## Varyasyon Promptları

### 1. Neutral Portrait
```
Master Octave portrait, neutral kindly expression, half-smile, looking
warmly at viewer. Same character spec as reference sheet. Bust-up framing.
```

### 2. Happy / Encouraging
```
Master Octave portrait, warm proud smile, eyes crinkled with kindness,
slight head tilt approvingly. Bust-up framing.
```

### 3. Surprised / "Oh!"
```
Master Octave portrait, eyebrows raised in pleasant surprise, mouth
slightly open in "oh!" shape, hand near beard in thoughtful gesture.
Bust-up framing.
```

### 4. Proud (Chapter Finale)
```
Master Octave portrait, warm proud smile with misty eyes, hand on heart
gesture, looking off-camera as if at Iris. Bust-up framing.
```

### 5. Wave (Greeting)
```
Master Octave half-body, raised hand waving warmly, friendly grandfather
welcome gesture, slight head bow.
```
