## Iris Full Reference Sheet Prompt

```
Character reference sheet for "Iris", 22-year-old female alchemist
apprentice in casual mobile puzzle game POURLE. Smooth 3D toon render in
Royal Match style with Pixar Toy Story / Inside Out smoothness.

Physical:
- Age: 22, young capable woman.
- Face: Soft oval face, mass-market neutral feminine features (NOT runway
  fashion model, NOT anime exaggerated, NOT chibi big eyes), small
  charming nose, friendly natural lips, light freckles across nose bridge.
- Eyes: Warm green or hazel-brown, curious bright expression default,
  natural realistic proportions (NOT anime-large).
- Hair: NATURAL CHESTNUT BROWN #7A4C2D shade (medium-dark warm brown).
  NEVER purple, NEVER lavender, NEVER pink, NEVER pastel, NEVER any
  K-pop accent color. Practical loose bun at nape with a few wisps free,
  OR a simple ponytail. Hair length shoulder-length when down. Simple
  thin headband or no accessory at all (NO ribbons, NO bows, NO flowers).
- Build: Average height, lean practical build (NOT exaggerated curves,
  NOT pin-up proportions, NOT idol idealized).
- Skin: Warm medium #E8C9A8.

Outfit (Apprentice — Chapters 1-5):
- Cream tunic top with rolled-up sleeves to forearms (practical for
  alchemy work).
- Amber-colored apron over tunic, with utility pockets for tools.
- Practical olive-brown trousers, comfortable cut, no fashion exaggeration.
- Sleeves have wide cuffs (alchemy fire protection lore).
- Simple leather belt with small pouch.
- Practical ankle boots in warm brown leather.
- NO jewelry, NO accessories beyond practical (small notebook tucked in
  apron pocket optional).

NEVER include:
- Princess gown or fancy formal dress.
- Magical girl outfit (heart-shape buckles, ribbon ties, frilly skirts).
- Ribbons, bows, hearts, stars as accessories.
- K-pop holographic / pearl / iridescent details.
- Anime large eyes / chibi exaggerated proportions.
- Pin-up cleavage or sexy fashion model framing.
- Witch hat or magical girl tiara.
- Idol-style runway makeup.
- Purple / lavender / pink / pastel hair color.
- Fashion model glamor pose default.

Color palette:
- Primary: Chestnut #7A4C2D
- Secondary: Warm beige #E8DCC0
- Accent: Apothecary green #5C8A3C (subtle in apron trim)
- Skin: Warm medium #E8C9A8

Style: Royal Match smooth 3D toon render (90%), Pixar polish (10%).
Vector-clean edges, soft gradient shading, bold readable shapes.
Mass-market neutral 50/50 gender appeal — must feel relatable to both
male and female players, NOT skewed feminine.

Mood reference: Hailee Steinfeld's "Hawkeye" character framing (capable
young hero), Anya Taylor-Joy's "Queen's Gambit" focused intelligence
(NOT fashion model), Disney's mature Anna from Frozen 2 (capable + warm).

Negative prompt: NO painterly, NO oil painting, NO brushstrokes, NO Clair
Obscur, NO Belle Époque, NO anime, NO chibi, NO magical girl, NO
princess, NO witch cosplay, NO purple/pink/lavender hair, NO ribbons, NO
bows, NO hearts, NO K-pop, NO pin-up, NO runway, NO holographic, NO
pearl, NO sailor moon, NO chibi big eyes, NO frilly, NO clinical lab.

Output format: Multi-pose character reference sheet showing front, 3/4,
side, with 5 portrait expressions (neutral, focused, excited, determined,
wave). Crisp 4K, asset pipeline ready.
```

## Varyasyon Promptları

### 1. Neutral Portrait
```
Iris portrait, calm friendly expression, slight smile, looking warmly at
viewer. Bust-up framing.
```

### 2. Focused (Working)
```
Iris portrait, focused concentration expression, eyebrows slightly down,
biting lower lip in thought, hand near chin in thinking gesture. Bust-up.
```

### 3. Excited (First Success)
```
Iris portrait, bright excited smile, eyes wide in joy, slight head tilt,
hands held up celebrating. Bust-up framing.
```

### 4. Determined (Chapter 5 Volcano Mission)
```
Iris portrait, determined firm expression, jaw set with confidence, eyes
focused forward, slight wind in hair as if facing challenge. Bust-up.
```

### 5. Wave (Greeting)
```
Iris half-body, raised hand waving warmly, friendly cheerful greeting
gesture, slight smile.
```

## Mistress Evolution Variant (Chapter 6 Finale)

```
Iris (now Mistress, Chapter 6), still 22 but with subtle confidence shift.
Same chestnut hair (NO color change), now in more refined updo bun with
a small gold hairpin (apothecary master symbol, NOT princess tiara).
Outfit upgraded: Same cream tunic but now with master-grade burgundy
piping (echoing Octave's color), her own apron in deeper amber, small
master pendant on chain (mortar-and-pestle, NOT occult).

Pose: Standing confidently behind tezgah, the apothecary now hers, soft
proud expression, slight smile suggesting both achievement and continued
curiosity.

Same negative prompt as base Iris reference sheet.
```
